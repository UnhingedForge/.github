# Contributing to UnhingedForge

Project repositories are private. Contributors receive access to the projects they are assigned to; organization membership does not grant access to every repository.

1. Open an issue or confirm the assigned task before making a substantial change.
2. Work on a branch and open a pull request with a clear summary and relevant verification results.
3. Preserve existing user data, compatibility requirements, licenses, and third-party notices.
4. Keep credentials, signing keys, customer records, personal data, local workspace records, dependencies, and generated build output outside source control.
5. Obtain maintainer review before merging. Repository administrators retain responsibility for releases, deployments, and access changes.

Follow any additional contribution and testing requirements in the individual project repository. A successful build or merged pull request does not by itself authorize a product release.
