# UnhingedForge

UnhingedForge is an independent software and game development company building practical tools, original games, and connected community experiences.

## What we build

- Desktop software and tools for players, creators, and server administrators.
- Original games, mobile applications, and game modifications.
- Discord bots and community management tools.
- Websites, package creation tools, and commissioned development projects.

## How we use GitHub

GitHub is our home for source control, issue tracking, code review, and collaboration. We keep each project in its own repository so its code, dependencies, and development history can be managed independently.

Our project repositories are private. Access is granted to authorized contributors for the projects they work on. Product releases and public downloads are published separately when approved and ready.

## Access and licensing

Repository access does not grant permission to redistribute source code, assets, or commissioned work. Each project retains its applicable license and third-party notices.
